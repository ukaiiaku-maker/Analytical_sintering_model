# Heating-rate figure caption

**Figure 1. Fixed-parameter heating-rate response for selected case P001.** All paths begin from initial state S03276 (relative density \(\rho_0=0.65\), grain size \(G_0=15\) nm, pore \(D_{50}=10\) nm), heat to 1500 °C with no hold, and differ only in heating rate: 0.2, 1, and 100 °C min⁻¹. Panels show (A) temperature history, (B) grain size \(G\) versus relative density \(\rho\), (C) grain size versus time, (D) density versus time, (E) the model-provided total densification rate `rho_dot_total` versus temperature, and (F) effective sintering stress `sigma_eff` in MPa. Panels B and C use logarithmic grain-size axes. Matched-density separation is read from panel B and the accompanying ratio source table. This is a fixed-parameter forward-prediction demonstration, not a fit, and the model is not validated.
