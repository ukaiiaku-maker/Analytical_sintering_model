# Massive latent-topology search for high-density two-step sintering

## Status

This is a mechanism-search negative result, not validation. The completed hierarchy evaluated 1,000,000 vectorized Stage-0 conditions, 5,000 reduced dynamic cases, 100 exact state-transfer cases, and 10 production-ranked cases. Projection-only scores were never assigned Tier A or B.

## Physical implementation

The reduced model explicitly evolves open, connected, isolated, and closed pore-volume stores, persistent junction state, and residual-stress memory. Store transfers are conservative. Density changes only through named open-pore and closed-pore shrinkage fluxes; the migration closure changes grain growth but not either density flux.

## Result

No Tier A or Tier B candidate survived exact dynamic scoring plus the complete Chen-window requirement. The best exact candidate reached a median high-density grain-size reduction of about 9%, below the required 20%. A separate exact candidate produced a complete 300 C classification window, but it was not among the candidates with useful high-density trajectory separation. Thus the objectives did not overlap.

High-density support was active, and many exact paths attained 0.98. This removes lack of density attainment as the sole explanation. The remaining failure is mechanistic: the current topology memories do not sustain enough migration contrast through 0.95–0.98 while retaining a lower densification-exhaustion boundary.

## Interpretation

The one-million-point surrogate successfully enriched dynamic candidates but substantially overpredicted reductions, which confirms that it is only a feasibility filter. Strong drag frequently caused universal high-density attainment or eliminated the lower Chen boundary. The best trajectory effects remained Tier C. Production fast-firing preservation and nucleation-facile/PR-off ablations remain incomplete because no Tier A/B candidate warranted promotion; existing E0021/E0142 material kinetics were not modified.

The next physical test should resolve boundary-segment populations and closed-pore attachment explicitly, so first-step state can suppress migration locally without making closed-pore shrinkage universal. No broader material-barrier search is justified by this result.
