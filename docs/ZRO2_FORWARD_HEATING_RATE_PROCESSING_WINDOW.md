# Heating-rate processing window

Across the complete 420-schedule heating grid, the fixed model predicts a strong but highly schedule-dependent matched-density fast-firing effect. The largest finite `G_reference/G_fast` is 46.84 for 0.2 versus 100 °C/min near density 0.946 in the 1500 °C zero-hold comparison. This extreme ratio arises because the slow path undergoes very large growth (`G ≈ 5.88 µm`) while the fast path remains near 0.126 µm; it is a forward prediction to test, not a fitted claim.

No fitting, optimization, or physics change was performed. Density changes only through named open and closed shrinkage fluxes. This is not validation.
