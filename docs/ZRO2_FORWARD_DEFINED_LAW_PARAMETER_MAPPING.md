# Defined-law parameter mapping

Fixed or transferred physical inputs are the fitted ZrO2 barrier, attempt frequency, Burgers-vector scale, `D_GB0=0.056 m²/s`, `Q_GB=380 kJ/mol`, `D_s0=0.10 m²/s`, and `Q_s=380 kJ/mol`. Geometry-derived quantities include triple-line density, event strain, pore radii, and the Zener radius/pinning factor.

The pore stores, PR memory/work, pore-size statistics, and accommodation state are evolving state variables. Stress, renewal times, Lambda, activity, density fluxes, and migration rates are computed diagnostics.

The growth prefactor is a global calibration and its activation branch remains bounded uncertainty. PR transfer coefficients, closed-transition times, accommodation capacity/recovery, and the reduced candidate transfer remain phenomenological. Closed pressure, shrinkable fraction, and transport length lack independent mappings. `Q_closed_app` is diagnostic only; `Q_closed_emp` and empirical scale are nonphysical diagnostics.
