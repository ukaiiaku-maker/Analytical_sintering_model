# Mobility versus resolved rules

Mobility controls only the upper grain-growth boundary. The resolved two-step mechanism remains PR-prepared closed-pore transition, bounded accommodation, and closed shrinkage. In the final closure-controlled implementation, none of the tested mobility modes produces density/growth overlap, so there is no mobility-only success to misinterpret.

PR memory, closed porosity, and accommodation remain active in every mobility case, but activity alone is insufficient: the lower density boundary stays above the upper growth boundary. Because no parent window exists, the destructive ablations cannot yet establish causal sufficiency. The model remains unvalidated.
