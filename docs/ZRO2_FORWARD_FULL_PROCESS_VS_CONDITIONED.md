# Full-process versus PDF-conditioned analysis

The full-process branch tests prediction from the physical green compact. The PDF-conditioned branch tests only kinetics over the observed 950–1500 °C interval. Their histories and summaries are stored in separate tables.

With the common conditioned state and unchanged original parameters, the 5 °C/min result is approximately 0.983 density and 2.15 µm, while 50 °C/min reaches about 0.932 density and 0.600 µm. Thus initialization accounts for part of the previous fast-path density deficit, but a thermal calculation still does not reproduce the microwave HMS density.

The conditioned calibration selected for trajectory comparisons improves the CS density-curve RMSE to 0.0213 but overshoots final density to 0.995. The distinct endpoint-conditioned fit reaches 0.9756 and 2.096 µm but has density-curve RMSE 0.0682. Conditioning removes the invalid start-state comparison but does not yield one parameter set that matches every CS trajectory and endpoint metric.
