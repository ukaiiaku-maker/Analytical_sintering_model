# Resolved-rule limitations

- The barrier is conservatively extrapolated below its fitted temperature range.
- Resolved PR, transition, and accommodation parameters are explicit but not independently calibrated.
- The exact Mazaheri two-step schedule and interrupted pore states remain unavailable.
- Enforcing late open-path exhaustion substantially lowers CS and fast-path density.
- No parent strict window exists, so destructive-ablation causality is not testable.
- Intrinsic mobility remains uncertain but is audited separately and never changes density directly.

The model is not validated, and the result should be treated as a conditional negative thermal baseline.
