# Common-state sensitivity interpretation

The 405-state primary factorial uses one common 950 °C state per condition and no method-specific initialization. Pore D50 dominates 50 °C/min density: its main-effect range is 0.178 in final density, versus 0.028 for isolation, 0.026 for pore width, 0.018 for starting density, and 0.0002 for starting grain size.

Pore D50 also has the largest mapped effect on the smaller-D90 sign. Fast smaller-grain behavior survives near the nominal state but is not robust across the factorial. No common state passes all fast-firing and two-step gates.

The descriptor controlling boundary gap is not identifiable from this factorial because it stored one representative two-step result per state, not a lower/upper boundary map or high-temperature comparator. No such effect is inferred. This is diagnostic sensitivity analysis and does not validate the model.
