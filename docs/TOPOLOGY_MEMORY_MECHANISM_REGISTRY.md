# Topology Memory Mechanism Registry

The machine-readable registry covers PR topology generation, connected removable-pore inventory, persistent junction/segment state, residual-stress memory, pore-filled versus structural TJ partition, and vacancy-accommodation multihit memory. Each entry declares states, evolution law, density/migration scope, conservative-flux status, observable signatures, parameters, and rejection criteria.

The registry is a hypothesis catalogue. It does not imply that all states are implemented in the production integrator.
