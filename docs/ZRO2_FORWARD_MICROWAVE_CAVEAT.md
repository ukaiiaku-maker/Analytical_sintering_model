# ZrO2 forward microwave caveat

The optional diagnostic is disabled by default (`microwave_mode=none`, multiplier 1). A 50 °C/min thermal path reaches density 0.8876. Multiplying effective nucleation activity requires an estimated factor of about 347 to reach density 0.98 (log interpolation between the tested 300× and 1000× cases).

This large effective multiplier is not calibrated microwave physics and is not part of thermal validation. It only quantifies the missing enhancement. LMS/HMS involve electromagnetic/volumetric heating effects not represented by the current local thermal laws.

CS endpoint agreement is not trajectory validation; the barrier is extrapolation-limited below 1557 °C; the TSS schedule remains unavailable; closed accommodation is a bounded proxy.
