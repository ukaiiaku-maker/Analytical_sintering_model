# Processing-window prediction limitations

The model is not validated. No data fitting or parameter optimization was performed. The failed global mobility fit was excluded, but the active default intrinsic growth branch remains provisional. Long second-step holds, a 0.90 target, reduced PR/accommodation state laws, sparse representative heating families, and unvalidated pore topology limit physical generalization.

The 5,020-state screen is space filling rather than the full 604,800-state factorial. Twenty-four diversity-ranked promotable states received the complete T2/hold/target scan. History CSVs are regularly sampled to fit the constrained workspace volume; classification endpoints were retained at full resolution.

Failure to reproduce a stronger fast-firing response is a fixed-forward mapping result and is not a reason to copy candidate 693168 values.
