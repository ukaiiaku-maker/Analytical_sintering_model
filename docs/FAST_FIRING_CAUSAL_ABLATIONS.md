# Fast-Firing Causal Ablations

All six prototype hits retained strict fast-firing separation when conservative PR redistribution was disabled. Their maximum ratios changed negligibly. Making nucleation facile removed the separation in every case, while the exchange-limited variant also produced no strict hits. The transport-only mode did not attain the shared interval and was rejected rather than scored.

The current model therefore demonstrates **nucleation sensitivity but not the requested PR-memory causality**. Removing the low-activity PR gate also left every hit intact. No seed survives the causal promotion rule.

The most direct interpretation is that temperature-dependent mean-grain growth accumulated during the longer reference ramp is sufficient to create the separation. The modeled conservative pore redistribution is diagnostically present but dynamically too weak—or too weakly coupled to later densification—to cause the effect.
