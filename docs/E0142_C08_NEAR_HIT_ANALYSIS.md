# E0142+C08 Near-Hit Analysis

Exact 10 C refinement from 950--1250 C shows the old isolated 1100 C point was a coarse-grid artifact. At the 5% second-step growth tolerance, successes span 1060--1110 C, bracketed below by density exhaustion and above by grain growth.

The window is narrow because density turns on near 1060 C while migration exceeds the growth tolerance above roughly 1110 C. It is not limited by T2<T1 in the examined T1=1300/1500 C states. This supports local pore-pinned migration suppression, but does not by itself validate C08 over the wider topology family.
