# E0021/E0142 Fast-Firing Timing Audit

E0021 remains the cleaner fast-firing mechanism: its 1.86 grain-ratio response disappears both when nucleation is facile and when grain growth is suppressed before activation. E0142 loses the effect with facile nucleation but retains it in the pre-activation-growth diagnostic, implying an additional timing contribution.

PR-off remains successful for both and is treated as compatible with nucleation-limited, PR-independent fast firing.
