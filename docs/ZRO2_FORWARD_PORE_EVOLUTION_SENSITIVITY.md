# ZrO2 forward pore-evolution sensitivity

Thirty-five bounded one-at-a-time cases varied connected redistribution, removal time, closure gates, closed shrinkage/capacity, Zener strength, and mobile drag. All integrations completed. Every eight-point coarse map had zero Chen successes, and no case satisfied the combined fast-path and two-level pathway criteria.

Closure and closed-accommodation variations were nearly inert because the predicted closed fraction is extremely small. Removal acceleration can recover density but not the grain-size/window criteria. Zener changes alter matched-density ordering, but none restores a finite lower-and-upper-bounded window. Most baseline variants preserve the smaller-grain thermal-rate sign; the required smaller-D90 sign at matched density is absent except for selected Zener-strength levels, which still fail the two-level criteria.

The OAT therefore provides no physically consistent Chen window and does not justify changing the calibrated model. Barrier uncertainty below 1557 °C remains primary. No schedule-specific memory or low-temperature mobility transition was introduced.
