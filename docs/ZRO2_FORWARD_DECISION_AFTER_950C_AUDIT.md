# Decision after the 950 °C audit

The recommended sequence is:

1. Measure or calibrate the common 950 °C pore-size/connectivity distribution.
2. Recover the exact TSS schedule and interrupted first-step pore/grain state.
3. Quantify open/closed fractions and pore-size evolution at the switch.
4. Only then decide whether closed-pore shrinkage, pinning, or low-temperature activity physics requires modification.

No OAT case passed every pathway gate, and the OAT gap response is too censored to select a model change. Reporting the negative thermal baseline is defensible while the required data are unavailable. The relaxed 2.0 µm/0.95 windows are diagnostic only, not TSS-like evidence. No validation claim is made.
