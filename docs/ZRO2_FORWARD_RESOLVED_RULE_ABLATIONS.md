# Resolved-rule ablations

All ten required ablations are implemented and labeled. They were evaluated in a 0.1× intrinsic-mobility context, but that parent context has no finite window after closure-controlled density was enforced. Consequently, destructive and preservation claims are not identifiable: universal failure cannot demonstrate that the first four ablations destroyed a parent behavior, nor that the latter six preserved one.

The four controlling hypotheses remain `no_PR_damage`, `no_closed_transition`, `no_closed_shrinkage`, and `infinite_closed_accommodation`. The non-controlling checks remain TJ multihit, residual stress, pore drag, persistent junction state, sweep/coalescence, and network heterogeneity. A causal ablation conclusion requires a parent resolved-rule window first. No validation claim is made.
