# Surface-diffusion / PR literature mapping

| Physical idea | Audit mapping | Status |
|---|---|---|
| Mullins/Nichols surface transport | (B_s\), (r^4/B_s) shape time | physical scaling; geometry coefficient unresolved |
| Solid-state dewetting/channel breakup | segment-to-radius instability index | geometry-guided bounded surrogate |
| Plateau–Rayleigh pinch-off | logistic transition about the circumference criterion | bounded uncertainty, conservative partition |
| Pore/Zener pinning | (R_Z\sim r/f_v\), (P_Z\sim f_v/r) | geometry scaling; migration only |
| Chen two-step window | lower densification, central success, upper growth boundaries | strict promotion criterion |
| Closed shrinkage | existing stress-resolved renewal/GB kernels | unchanged; requires inventory, stress, and accommodation |

Primary seeds retained from the preceding audit include Nichols and Mullins,
J. Appl. Phys. 36 (1965), DOI 10.1063/1.1714360; Chen and Wang, Nature 404
(2000), DOI 10.1038/35004548; Wang, Chen and Chen, JACS 89 (2006), DOI
10.1111/j.1551-2916.2005.00763.x; and pore-pinning literature represented by
Watanabe and Masuda (1982), DOI 10.2497/jjspm.29.151. Repository ZrO2 PDFs supply
the material-specific sintering context.

The literature motivates response forms, not numerical ZrO2 fitting. The contact
angle, channel geometry, surface-site factor, partition, and transition width are
not sufficiently measured; they remain geometry-derived, bounded, or
semi-phenomenological. Candidate 693168 supplies no parameter values.

This mapping is not validation. No validation claim is made.
