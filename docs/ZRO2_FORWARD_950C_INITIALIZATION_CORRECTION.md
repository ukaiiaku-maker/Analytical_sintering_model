# 950 °C initialization correction

The earlier overlay mixed a full-process prediction beginning at 25 °C, density 0.4840, and grain size 10.2 nm with experimental curves whose first visible points occur near 950 °C, density 0.65–0.67, and grain size about 50 nm. The earlier delay is therefore relabeled an **initialization/pre-950 °C prediction mismatch plus possible barrier-extrapolation effect**, not solely a barrier-onset error.

The corrected analysis retains the green-state calculation separately and introduces one common conditioned state for every post-950 path: 950 °C, density 0.66, grain size 50 nm, all porosity initially open, and a common volume-weighted pore D50 of 25.78 nm (nominal requested scale 25 nm). No method-specific initial state is used.

At 950 °C the full-process 5 °C/min prediction is density 0.4842 and grain size 10.73 nm, missing the common entry state by -0.1758 density and -39.27 nm. The PDF contains no measurements below its first plotted interval, so no missing observations are overlaid there.
