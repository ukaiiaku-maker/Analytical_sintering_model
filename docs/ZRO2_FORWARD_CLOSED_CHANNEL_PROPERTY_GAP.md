# Closed-channel property gap

This audit is not validation. `Q_closed` is proxy/unidentified in the current physics. For candidate-like and naturally prepared resolved states, finite-difference log-rate slopes give approximately 118–137 kJ/mol. Relative to `Q_growth=405.24 kJ/mol`, the gap is −288 to −268 kJ/mol, below the promoted both-pass interval of −252 to −127 kJ/mol.

Using the 380 kJ/mol surface/PR channel, `Q_PR−Q_closed,eff` is about 243–262 kJ/mol, above the promoted upper bound of 212 kJ/mol. Using the separate 180 kJ/mol resolved PR barrier, the alternate difference is 43–62 kJ/mol and lies inside. This dependence on PR mapping reinforces that the comparison is diagnostic rather than a calibrated property identification.

The decisive result is rate magnitude: closed/growth prefactor ratios extend several decades below the promoted lower bound, closed availability is absent in open-only states, and even the earlier 100x closed-rate audit did not recover fast density. The problem is therefore not simply a high `Q_closed`; it is an under-specified effective closed prefactor, inventory availability, and accommodation coupling.
