# Next calibration recommendation

No bounded OAT case passed every pathway-consistency gate, so none is accepted as a physically consistent calibration candidate in this audit. The highest-value future measurement is the pore-size/connectivity distribution at the common 950 °C entry state, because pore D50 dominates fast density attainment and materially changes both grain and D90 signs.

Future calibration should constrain common pore D50, width, and isolation jointly before calibrating closed accommodation or pinning. It should retain the separation between full-process and PDF-conditioned analyses, keep microwave LMS/HMS as comparison targets rather than thermal validation, and preserve strict Chen criteria. Relaxed thresholds are diagnostic only. Barrier extrapolation below the fitted range and the bounded closed-accommodation proxy remain limitations. No validation claim is made.
