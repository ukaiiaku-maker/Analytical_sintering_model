# Defined-law port results

The direct defined-law port exactly reproduced the current baseline fixed ramps: final density 0.937011 and grain size 0.937857 µm at 5 °C/min; density 0.900504 and grain size 0.258471 µm at 50 °C/min. All runs began from the same 950 °C, density 0.66, grain size 50 nm state.

In the injected candidate-like state, the reduced transfer produced five strict T2 successes with both low-side density failures and high-side growth failures. Nominal GB and gas mappings produced ten successes but removed all available closed inventory and lost the low boundary. Renewal-limited and empirical mappings remained too weak.

For states naturally prepared by each mode, every mode produced zero strict success. None passed the required low-failure/intermediate-near-success/high-growth-failure topology gate, so no mini-map was run: strict mini-map successes and finite windows are both zero.

This distinguishes state preparation and parameter mapping from law availability. The law set exists, but the reduced candidate state/rate combination is not generated naturally by the current ZrO2 mapping. No validation is claimed.
