# Dynamic Chen Reintegration for Nucleation Materials

The bounded exact-state audit used two selected materials, all 11 topology families, G0=75/225/600 nm, T1=1300/1500 C, 20 C/min first steps, switch density 0.80/0.88, and T2=800--1500 C in 50 C increments. Every first-step state was transferred exactly and topology evolved through the second step.

There were 4,088 grain-growth failures, 2,922 densification-exhaustion failures, 902 mixed failures, and eight successes. All eight successes were the same isolated 1100 C point for E0142+C08 at G0=600 nm across tolerance and preparation variants. Because the sampled success width is zero, these are classified `ISOLATED_SUCCESS_NOT_WINDOW`, not complete windows.

No q0 or q1 multihit family produced a finite practical dynamic window. The earlier fixed-state overlap is therefore not confirmed.
