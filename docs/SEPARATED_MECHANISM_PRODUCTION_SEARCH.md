# Separated-Mechanism Production Search

The checkpointed campaign completed Phase A and a 512-material Phase B. Phase B evaluated 6,144 schedule comparisons: 3,193 attained the common interval and 84 met the raw strict trajectory rule. Twenty-two distinct best-case near hits were causally ablated. None lost the effect when PR redistribution was disabled, so there were zero promotable material sets.

Consequently Phases C and D were stopped by design. This is an auditable negative result, not an incomplete computation caused by runtime. `run_state.json` records the terminal gate and the compact CSVs preserve every scored comparison.

The next model change should not be a broader parameter sweep. It should make conservative pore redistribution observably affect a named later densification eligibility state—such as connected removable pore inventory—then demonstrate that the coupling is independently measurable and not an efficiency multiplier.
