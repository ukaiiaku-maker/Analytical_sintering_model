# Strict Window Tier Analysis

Exact rechecks were performed for every previously finite boundary using preparation tolerances of 5%, 10%, and 20% and second-step tolerances of 5% and 10%. G1 was recomputed from each exact first-step state.

No Tier A window survives. E0021 has no Tier A or Tier B result: its 24 tolerance-specific surviving rows are Tier C, with the finest prepared state about 352 nm. E0142 has five unique Tier B material/topology/preparation windows (15 rows when the three satisfied preparation-tolerance declarations are retained). Their G1 values are about 303--304 nm, widths are 30--40 C, preparation growth is 0.98--1.44%, and second-step growth reaches 7.5--9.5%.

Both qTJ=0 and qTJ=1 retain Tier B examples. Tier A fails because second-step growth exceeds 5%, not because preparation growth or G1 is excessive. The broadest 180 C E0142 window remains Tier C because its prepared state is coarse and/or its second-step growth exceeds strict limits.
