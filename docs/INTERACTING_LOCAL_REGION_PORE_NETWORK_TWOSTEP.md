# Interacting local-region pore-network two-step model

This prototype tests whether spatial variance can retain connected densifying regions alongside clean, isolated, or closed regions. Stage-0 screening is never tiered; exact 30-minute reconfirmation is mandatory. No validation claim is made.

The run evaluated 1,000,000 surrogate conditions, retained 20,000 reduced rows, and exactly reconfirmed 1,000 rows. Because the current dynamic parameter decoder maps candidates only onto the three implemented network resolutions, those rows reduce to three dynamic equivalence classes. No Tier A/B result was found. This limitation is explicit: the result is a topology-network prototype, not a broad dynamic parameter exploration.
