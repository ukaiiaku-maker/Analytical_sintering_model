# Empirical closed-closure caveat

`empirical_closed_rate_scale` is an explicitly diagnostic reduced law: `k0_closed_emp exp(-Q_closed_emp/RT) phi_closed A_closed size_factor`. It exists only to bound the missing rate scale and boundary risk. `Q_closed_emp` is an apparent fitting coordinate, not a ZrO2 material property, and this result never overwrites a physical-law result.

The tested scale factors were 1, 30, 100, and 300. They helped density while preserving a lower boundary in the injected-state audit, but did not establish a naturally prepared strict Chen window. No empirical parameter is calibrated or validated.
