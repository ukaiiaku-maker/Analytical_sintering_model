# ZrO2 forward barrier extrapolation audit

Four explicit modes were tested without refitting JSON slices. The nearest-slice clamp gives a 326 °C CS onset error and thermal 50 °C/min density 0.888. Mathematical PCHIP extrapolation reduces these to 279 °C and 0.962. A lowest-two-slice fixed-slope diagnostic reduces onset error to 72 °C and raises fast-path density to 0.975. The generic anchored barrier behaves similarly but is non-JSON diagnostic evidence only.

The clamp therefore controls a large part of the onset and fast-density failure. It does not fully explain the missing Chen window: none of the three JSON-derived modes produced a coarse-map success. Only the non-JSON generic anchor produced three coarse successes, which cannot support validation.

All calculations below 1557 °C are labeled extrapolated or clamped. No new barrier data were invented.
