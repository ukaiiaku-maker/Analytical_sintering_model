# Material-property window figure manifest

All figures are in `results/relative_material_property_window_attribution/figures/` as vector PDF and 600 dpi PNG. They describe a conditional mechanism attribution, not validation or paper readiness.

| Figure | Purpose |
|---|---|
| `mechanism_ingredient_summary` | separates fast-firing, shared, and two-step chains |
| `fast_firing_mechanism_attribution` | exact trajectory, dimensionless groups, and nucleation/PR ablations |
| `two_step_mechanism_attribution` | matched-density separation, closed support, and bracketed boundaries |
| `relative_barrier_window_fast_firing` | exact relative-barrier maps for span and ratio |
| `relative_barrier_window_two_step` | exact barrier/prefactor maps for reduction and Chen width |
| `joint_behavior_phase_map` | exact fast-only/two-only/both/neither classification |
| `sensitivity_tornado_fast_firing` | exact rank associations with fast ratio |
| `sensitivity_tornado_two_step` | exact rank associations with Chen width |
| `closed_accommodation_plausibility_window` | closed state, selectivity, reduction, and window width |
| `six_TierB_material_window_comparison` | reduced transfer across all six Tier-B candidates |
| `common_particle_system_trends` | qualitative relative-property trends and shared tests |

Machine-readable file paths and descriptions are in `source_tables/figure_inventory.csv`.
