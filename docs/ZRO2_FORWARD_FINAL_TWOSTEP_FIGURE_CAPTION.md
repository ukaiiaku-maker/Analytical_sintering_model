# Two-step figure caption

**Figure 2. Two-step and high-temperature isothermal responses for selected case P014.** Each path begins from S00579 (\(\rho_0=0.75\), \(G_0=33\) nm, pore \(D_{50}=10\) nm), heats at 100 °C min⁻¹ to \(T_1=1500\) °C, and uses the identical stored switch state (actual \(\rho_1\approx0.832\), \(G_1\approx37.82\) nm). The second-step paths are 850 °C (density-exhaustion failure), 925 °C (central strict success), and 1025 °C (grain-growth failure), each for 96 h; the comparator remains at 1500 °C. Physical time is continuous across the switch and is not re-zeroed. Panels show (A) temperature, (B) grain size versus density, (C) grain size versus time, (D) density and the \(\rho=0.90\) target, (E) total densification rates plus the central-success open- and closed-pore contributions, and (F) the Chen-style \(G_1\)-\(T_2\) map. Map colors denote density exhaustion (blue), strict success (green), grain-growth failure (orange-red), mixed failure (purple), unattainable state (light gray), and target already reached (dark gray). A finite window requires both a lower density-exhaustion boundary and an upper grain-growth boundary; the selected strict window is 875–1000 °C. This is a fixed-parameter prediction, and the model is not validated.
