# Figure Caption Drafts

## Main text

**M1 — Mechanism overview.** Reduced-order architecture separating renewal
densification, non-densifying PR/de-sintering memory, and grain-boundary
migration. Pore-filled triple junctions may relax compatibility or impose
Class-A drag, whereas Class-B multihit completion acts on structurally
constrained junctions.

**M2 — Variable definitions.** Primary state variables and diagnostics used in
the processing maps. The notation links macroscopic density and grain size to
observable connected-pore memory and junction-state variables.

**M3 — TJ population modes.** Schematic partition of pore-filled TJ coverage in
the four migration-only ablations. The old all-TJ limiting case is compared
with relaxation, pore drag, and mixed interpretations without changing TJ
densification.

**P1 — Representative thermal histories.** Temperature histories for slow and
fast firing and for high-temperature isothermal and two-step processing. These
protocol families define the comparisons used throughout the response maps.

**P2 — Representative evolution histories.** Density, grain size, connected
mean pore radius, and connected fine-pore fraction for the four representative
paths. Fast firing traverses the damaging intermediate-temperature interval
quickly, while the low second step limits grain migration after preparation.

**P3 — Density–grain-size trajectories.** Direct sintering trajectories for
slow, fast, high-temperature, and two-step paths. A favorable path reaches a
given density at smaller $G$, displaying densification efficiency without
using a raw time comparison.

**P4 — Density–pore-size trajectories.** Connected mean pore radius and
large-pore fraction plotted against relative density. The separation between
paths demonstrates observable pore-distribution memory rather than an inferred
scalar efficiency.

**P5 — Fast-firing response map.** Median matched-density grain-size improvement
as a function of peak temperature and heating rate for four initial topology
classes at $\rho=0.90$. Positive and negative regions coexist, showing that the
PR-memory mechanism does not create universal fast-firing success.

**P6 — Practical Chen-style window.** Complete practical 5%/5% windows plotted
against prepared grain size, including lower densification-exhaustion and upper
grain-growth boundaries. Color indicates the finite temperature-window width;
censored windows are excluded.

**P7 — Joint scorecard.** Frozen-base status for practical Chen windows,
beneficial fast firing, and their coexistence. All moderate PR candidates pass
both production criteria with the same parameters.

**P8 — Matched-path PR memory.** Cumulative PR work, connected fine-pore
fraction, connected mean pore radius, and large-pore fraction along slow and
fast paths. The fast path retains a more removable connected pore population
at matched density while accumulating less non-densifying work.

**P9 — Two-step migration suppression.** Persistent junction state, TJ activity
ratio, multihit completion, and migration dissipation along a representative
two-step trajectory. Their second-step evolution identifies migration
suppression as distinct from the early PR-memory pathway.

**P10 — TJ-mode ablation.** Canonical Chen-positive, fast-beneficial, and
joint-positive counts for four TJ population interpretations. Pore-pinned and
mixed modes remain positive for all frozen bases, so pore-filled TJs need not
be treated wholesale as structural multihit constraints.

**P11 — Success correlations.** Fast response versus PR exposure, retained fine
pores, and TJ activity, together with window width versus prepared grain size.
The panels show useful conditional trends while warning that no single raw
occupancy variable uniquely predicts success.

## Supplement

**S1 — Frozen-base fast maps.** Separate production response maps for all four
frozen bases. The panels expose candidate-specific magnitude and temperature
structure hidden by the compact main-text summary.

**S2 — q0/q1 comparison.** Beneficial fast-firing counts for q0 and q1 under
each TJ interpretation and base family. The `mech_009` family is more sensitive
to the size exponent than the `mech_019` family.

**S3 — PR parameter sensitivity.** Heating-rate improvement for every bounded
one-at-a-time PR variant. Color distinguishes variants that retain both a
canonical Chen window and beneficial fast firing.

**S4 — TJ population histories.** Density-resolved pore, constraint, relaxed,
and pinned TJ fractions for all four interpretations. The figure verifies that
the model does not silently identify pore occupancy with structural constraint.

**S5 — Power and stress histories.** Representative densification power,
activation stress, persistent-junction dissipation, and multihit dissipation.
These channels remain named and separate in the Onsager-style partition.

**S6 — Failure and censoring.** Counts of failed and censored adaptive Chen
classifications. The distribution documents that incomplete bounds and failed
targets are retained rather than scored as windows.

**S7 — Attainment map.** Fraction of production fast-firing records that fail
to reach the requested density, resolved by peak temperature and heating rate.
This map identifies where matched-density response metrics are unavailable.
