# Next-Physics Decision After the Heterogeneity Search

The heterogeneous/residual-stress branch proved that broad, tailed, bimodal,
and correlated initial states produce visible pore-distribution memory, and
that residual stress can amplify it. Neither ingredient alone nor their
bounded combination creates a sustained meaningful mean-grain trajectory.

C091 failed because its ratio above 1.5 spans only density 0.850--0.858 and the
reference path ends at density 0.859. Its residual large-pore stress relaxes by
about twelve orders of magnitude relative to the peak. This points to missing
persistent defect/topology-stress memory in the early/intermediate regime.

The selected next branch is:

`codex/persistent-defect-topology-stress-memory`

It will test a conservative, slowly relaxing defect population and stored
PR/shear stress below density 0.92. Late-stage closed-pore physics is deferred:
the decomposition provides no evidence that the effect requires density 0.95
or above, and adding it now would confound two distinct hypotheses.

The observable gate remains unchanged: mean-grain ratio at least 1.5 over a
jointly attained `Delta rho >= 0.03`. Censored or unattained intervals are not
scored.
