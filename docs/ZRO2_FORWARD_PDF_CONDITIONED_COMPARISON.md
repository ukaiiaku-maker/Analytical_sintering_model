# PDF-conditioned ZrO2 comparison

All CS-like, LMS-like, and HMS-like thermal comparisons use the identical nominal state at 950 °C: density 0.66, grain size 50 nm, common open-pore arrays, no isolated or closed porosity, and no method label in a constitutive law.

Using the observed-curve calibration, the conditioned 5 °C/min path ends at density 0.9950 and grain size 2.192 µm; the 50 °C/min path ends at 0.9592 and 0.688 µm. The HMS density miss is reduced from -0.0924 in the full-process comparison to -0.0208, but remains. Over the jointly attained density interval, the 50 °C/min path has smaller grains for about 80% of sampled densities, though the ordering weakly reverses near the upper common density. The required smaller-D90 sign is present at only about 6% of matched points.

Initial-pore sensitivity is substantial: a 15 nm nominal D50 lets the 50 °C/min path reach 0.9878 density, while a 40 nm state reaches only 0.8856. These are controlled common-state sensitivities, not fitted method-specific states. Microwave-assisted LMS/HMS measurements remain comparisons, not thermal validation.
