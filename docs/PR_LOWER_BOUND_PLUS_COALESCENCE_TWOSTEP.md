# PR lower bound plus pore coalescence

The focused search evaluated 250,000 feasibility combinations, 5,000 reduced dynamic candidates, and 500 refined 25 C T2 scans. PR was implemented as an observable energy-diversion and conservative pore-redistribution channel, not as a fast-firing requirement.

One candidate restored a complete 50 C Chen window with lower densification exhaustion and upper grain-growth failure. It attained high density on both canonical paths but produced only 11.3% median reduction, below Tier B. Separate candidates produced 25–31% median reduction across the full 0.95–0.98 interval but lacked the lower boundary. No Tier A/B candidate joined both objectives.

The lower boundary correlates with persistent low-activity PR loss of connected fine pores into large, isolated, and closed stores. The upper boundary remains grain-growth activation. This is mechanism evidence, not validation.
