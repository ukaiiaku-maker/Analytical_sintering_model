# Reframed relative material-property window

The frozen 512-material registry is reanalyzed without penalizing large two-step reductions. This is a coverage audit, not a new optimization. Only E0021 and E0142 have the complete causal fast-firing audit; only E0142 has Tier-B Chen overlap in the archived strict window calculation. The closed-accommodation candidate family is not dynamically coupled to those material records, so no row is promoted to a fully coupled joint-material validation.

The shared causal fast-firing ordering is:

- disconnection-nucleation barrier above the GB-diffusion barrier;
- surface-evolution barrier above the GB-diffusion barrier;
- exchange and transport remain distinct, with transport-only and exchange-limited variants unable to reproduce the causal fast-firing response;
- nucleation-facile ablation removes the effect, while PR-off may preserve it.

E0142 currently provides the only observed joint qualitative fast-firing/Tier-B-Chen point. E0021 preserves the cleaner causal fast-firing timing but has Tier-C Chen behavior. Consequently the tables report observed property differences and ratios, not universal threshold bounds. A single joint point cannot identify a material-property interval.

Large two-step reductions remain favorable when both paths attain the scoring interval, the Chen window is complete, and numerical/state-variable checks pass. Future work must couple a frozen material record to the closed-pore/accommodation topology model at shared state, then vary relative properties while holding topology fixed. Until that interface exists, `joint_full_evidence_pass` remains false by construction.
