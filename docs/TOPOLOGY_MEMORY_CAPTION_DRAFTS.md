**Persistence projection.** Exponential diagnostic projections over registered memory times. Curves are screening constructs, not validated state histories.

**Baseline Chen windows.** Previously confirmed strict-tier windows shown as the target for future family-specific dynamic integration; they are not attributed to a new memory family.
